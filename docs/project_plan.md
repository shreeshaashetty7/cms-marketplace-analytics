# CMS Marketplace Enrollment Analytics: Full Project Plan

## Goal
End-to-end analysis, from raw CMS public files to a published dashboard and written insights.

## Stack
- Python / Jupyter Notebooks (for ingestion, exploration, and data cleaning)
- Git/GitHub (for version control)
- Excel / Local storage (for quick inspection)

## Scope
- One plan year (2026)
- Individual market only
- ~8-10 states

---

## Phases Overview
- **Phase 0: Setup** (Folder structure, Git repo, README starter)
- **Phase 1: Problem Definition** (Business questions, scope, state selection)
- **Phase 2: Data Acquisition** (Downloading OEP and QHP files, sources documentation)
- **Phase 3: Data Understanding** (Grain, key columns, data notes)
- **Phase 4-5: Cleaning & Transformation** (Handling suppressed values, parsing types, filtering)
- **Phase 6: Data Modeling** (Aggregating and joining datasets safely)
- **Phase 7: Analysis & Insights** (Querying / analyzing trends)
- **Phase 8-10: Dashboard, Documentation & Publishing**
